# Community PromQL UI

Community PromQL is exposed by the native frontend in `frontend/`. The old
compiled Prism overlay and archive download have been removed. Follow the
[native UI build and compatibility notes](native-ui.md) to build from source.
The [PromQL API guide](promql.md) describes the supported language and limits.

The server's PromQL capability flags and Prism API endpoints remain backend
contracts; retiring the classic distribution does not remove them.
